Case-study section patterns for eaglesimbeye.com, built from native WordPress
blocks and styled to the Claude Design system — no Elementor.

== What it does ==

Adds an "EES — Case study" category to the block inserter (Add block >
Patterns) with six reusable sections that match the anatomy of the existing
case studies:

* Case: Hero — full-bleed media, eyebrow, title, tagline, scroll cue
* Case: Overview grid — Scope / Timeline / Industry / Location / Role / Agency
* Case: Pillars — "what success required" (five titled cards)
* Case: Method steps — numbered Analysis / Hypothesis / Testing rows
* Case: Results / metrics — big figures with labels
* Case: Next project — large linked title to the next study

Every pattern is made of core blocks, so it is fully editable in the normal
WordPress editor with no page builder. Styling and fonts are carried by the
plugin and load in both the editor and the front end.

== How to build a case study ==

1. Create a new Page (or a duplicate of an existing case study to keep its URL).
2. Add block > Patterns > "EES — Case study" and insert the sections you need,
   in order (Hero, Overview grid, then narrative Pillars / Method steps /
   Results, and Next project at the end).
3. Replace the placeholder copy, images and metrics with the real content.

The placeholder text is modelled on the Lexus EU study; swap it per project.

== Install ==

WordPress admin > Plugins > Add New > Upload Plugin > choose ees-patterns.zip >
Activate. Works alongside (and independently of) the EES Chrome plugin.
